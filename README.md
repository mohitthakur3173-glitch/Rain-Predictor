# Rain-Predictor
Beginner-friendly ML model web app using Flask
This project is a beginner-friendly machine learning web application built using Flask.
The trained ML model is integrated with a web interface to make predictions based on user input.

## Tech Stack
- Python
- Flask
- Scikit-learn
- NumPy
- HTML/CSS

## How to Run Locally

1. Clone the repository
git clone https://github.com/your-username/your-repo-name.git

2. Install dependencies
pip install -r requirements.txt

3. Run the Flask application
python app.py

4. Open your browser and visit
http://127.0.0.1:5000

## Machine Learning Model

- The model is trained using Scikit-learn
- It takes numerical input from the user
- It returns predictions displayed on the web interface
